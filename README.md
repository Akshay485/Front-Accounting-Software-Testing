# Front Accounting – Software Testing Project

## Project Overview
This project focuses on manual software testing of Front Accounting, a web-based ERP accounting application designed to manage business operations.

The objective of this project is to validate the functionality, reliability, and quality of the application through systematic software testing.

## Application Details
- **Application:** Front Accounting
- **Version:** 2.4.56
- **Project Type:** Manual Software Testing
- **Testing Approach:** Black Box Testing
- **Defect Tracking Tool:** JIRA
- **Browsers:** Google Chrome and Mozilla Firefox

## Modules Covered
1. Login
2. Sales Management
3. Purchase Management
4. Items and Inventory Management

## Testing Activities
- Understanding functional requirements
- Preparing test scenarios
- Writing detailed test cases
- Executing test cases
- Identifying and reporting defects
- Tracking defects and their status


## Project Deliverables
 Test Plan : Defines testing scope, approach and strategy 
 Test Scenarios : Defines different testing conditions 
 Test Cases : Contains test steps and expected results 
 Defect Report : Documents identified defects 

## Tools Used
- Microsoft Excel
- JIRA
- Google Chrome

- Understanding the Software Testing Life Cycle (STLC)
- Preparing structured test documentation
